# Дашборд группы музыкальных экспертов

Рабочий дашборд задач: постоянные (с повтором и дедлайном), запланированные (к сроку) и влёты. Статусы как в Jira, быстрые ссылки с цветами, светлая и тёмная тема.

## Как открыть

Включите GitHub Pages для этого репозитория (Settings → Pages → ветка `main`, папка `/root`), страница будет доступна по адресу `https://<аккаунт>.github.io/<репозиторий>/`.

Можно открыть и просто как файл: `index.html` в браузере.

## Где хранятся данные

В этой версии задачи и ссылки хранятся в браузере, в котором открыта страница. Для переноса на другой компьютер или резервной копии используйте кнопки «Экспорт» и «Импорт» в шапке: они сохраняют и загружают JSON-файл. Тот же формат понимает и версия дашборда в Claude.
